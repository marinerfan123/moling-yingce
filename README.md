# 墨灵

墨灵是一个面向 AI 影视与内容创作的开源工作台，提供自由画布、图片/视频/音频生成、素材管理和异步任务能力。

## 项目说明

本项目用于本地开发和自部署。配置、数据结构及外部接口仍在持续迭代，请在可信环境中使用，并在公开部署前完成认证、CORS、存储和密钥安全配置。

## 更新说明

### 2026-09-14

- 修复火山方舟 Seedream 图像生成默认响应格式，优先接收临时 URL 并由后端持久化。

- 支持临时图片 URL 下载到资源存储或 OSS；OSS 不可用时沿用现有本地存储降级逻辑。
